# cpp-queue-practice
## 📌 Задача 1. «Обслуживание клиентов»

### Описание:
Есть очередь из `n` клиентов. Каждому клиенту нужно `t_i` минут на обслуживание. Обслуживаем строго по одному, в порядке очереди (FIFO). 
Нужно для каждого клиента вывести минуту, в которую он закончит обслуживание (накопительное время).

## 📌 Задача 2. «Переворот очереди»

### Описание:
Заполнить очередь числами. Перевернуть её порядок (первый стал последним), используя только queue и дополнительные контейнеры (например, std::stack или std::vector). Вывести результат.

## 📌 Задача 6. «Первый уникальный элемент в потоке»

### Описание:
Дан поток чисел. Для каждого нового числа нужно вывести первое число в потоке, которое встречалось ровно один раз (самое раннее уникальное). Если такого числа нет, вывести -1.
